# ☕ Coffee Shop Mobile App UI/UX Design

## 📌 Overview

Coffee Shop is a modern mobile application designed to provide users with a smooth and enjoyable coffee ordering experience. The interface focuses on simplicity, intuitive navigation, and a visually appealing design that enhances the overall user journey.

---

## 🎯 Project Objectives

- Design a clean and modern mobile interface.
- Simplify the coffee ordering process.
- Improve usability through intuitive navigation.
- Create a consistent and engaging visual design.

---

## ✨ Key Features

- User Authentication
- Home Dashboard
- Coffee Categories
- Product Details
- Cart
- Checkout
- Order Confirmation
- User Profile

---

## 👥 Target Users

- Coffee lovers
- Daily commuters
- Students
- Working professionals

---

## 🛠️ Tools Used

- Figma
- Auto Layout
- Components
- Variables
- Interactive Prototyping

---

## 🎨 Design Style

- Modern UI
- Minimal Layout
- Mobile-First Design
- Soft Color Palette
- Clean Typography
